# Terraform Zero to Hero 🚀

My learning journey through Terraform, HashiCorp's Infrastructure as Code 
(IaC) tool, following a structured 7-day roadmap — from writing my first 
`.tf` file to managing multi-environment infrastructure with remote state 
and secrets management.

## 📅 Roadmap

| Day | Topic |
|-----|-------|
| 1 | Getting Started — IaC concepts, installation, first Terraform code, EC2, state basics |
| 2 | Advanced Configuration — providers, resources, variables, outputs, conditionals, functions |
| 3 | Modules — reusable infrastructure, local values, data sources, Terraform Registry |
| 4 | Collaboration & State — Git workflow, .gitignore, S3 backend, DynamoDB state locking |
| 5 | Provisioners — remote-exec, local-exec, creation/destruction hooks, failure handling |
| 6 | Workspaces — managing multiple environments (dev/staging/prod) |
| 7 | Security — HashiCorp Vault integration for secrets management |

## 🛠️ Tools & Tech
- Terraform CLI
- AWS (EC2, S3, DynamoDB)
- HashiCorp Vault
- Git

## 📌 Goal
Build practical, hands-on familiarity with Terraform — writing 
declarative infrastructure code, managing state safely, creating 
reusable modules, and following IaC best practices for team 
collaboration.
